# UCA annotation preparation

UCA provides UCF-Crime event descriptions with start/end times. The upstream repository publishes `UCFCrime_Train.json`, `UCFCrime_Val.json`, and `UCFCrime_Test.json` under `UCF Annotation/json`. Each record has a video name, duration, timestamp pairs, and corresponding sentences. UCA is an annotation resource; the UCF-Crime videos are separate.

## Prepare the local review table

From `XDVioAlt/`, run:

```bash
.venv/bin/python scripts/prepare_uca_intervals.py
```

The script downloads the three official JSON files into `data/raw/ucf_crime/uca/json/`, matches records to videos already under `data/raw/ucf_crime/Videos/`, and writes:

- `data/annotations/uca_intervals_review.csv`
- `data/annotations/uca_intervals_review_summary.json`

If network access is unavailable, download the JSON files from the [official UCA annotation folder](https://github.com/Xuange923/Surveillance-Video-Understanding/tree/main/UCF%20Annotation/json) into `data/raw/ucf_crime/uca/json/`, then rerun the command.

## Review policy before training

The `candidate_labels` field is generated by conservative keyword matching. It is a search aid, not a model label. Review candidate intervals against the caption and video. Set `review_label` to exactly one of `fighting`, `shooting`, `riot`, `abuse`, `car_accident`, `explosion`, `normal`, or `ignore`. Use `normal` only after verifying that interval as a negative; use `ignore` for uncertain or irrelevant intervals. Keep it blank until reviewed. Do not infer that a caption with no violence keyword is a normal interval. Unannotated time remains unknown.

For a video-first workflow, launch the local review interface from `XDVioAlt/`:

```bash
.venv/bin/streamlit run scripts/uca_review_app.py
```

It defaults to the 51 training-split intervals with an `abuse` keyword candidate. It plays the relevant time window, displays the UCA description, and saves the selected label and notes directly into `uca_intervals_review.csv`. You can change the category or split filters in the interface. The preparation script preserves those decisions when rerun.

After reviewing training-split rows, export only reviewed labels with:

```bash
.venv/bin/python scripts/export_reviewed_uca.py
```

This creates `data/annotations/uca_intervals_supervised_train.csv` and a summary JSON. It exports `target_binary=1` for any reviewed violence class and `target_binary=0` only for reviewed `normal` intervals. Blank and ignored rows, plus all UCA validation/test rows, are excluded.

Only `train` split rows can be used for fitting. Keep UCA `val`/`test` separate, and keep all intervals from one video in one split. XD-Violence's official test set remains a separate benchmark. The local UCF provenance describes the Abuse category as broader than this project's abuse target, so category membership alone must not mark a clip as project-defined abuse.

These are *unreviewed candidate counts*, not confirmed labels or final training-example counts. The UCA split is video-disjoint: use only its train rows for fitting, and keep val/test rows out of training. The local UCF provenance note records that the official UCF test Abuse clips were excluded.

The project-level six-class binary target is “any of the six incident types versus normal.” UCA-derived positive intervals can add localized training supervision after review. It cannot by itself establish genuinely normal negatives or prove abuse performance; those require appropriately labeled negative examples and a separate held-out evaluation.

## Prepare live-compatible features

Feature extraction does not assign labels and can be done before review. It extracts the locally available UCA videos into separate split directories using the trained MiniRGB weights and the live path's canonical 24 fps / mono 16 kHz profile:

```bash
.venv/bin/python scripts/extract_uca_features.py
```

Outputs are resumable under `data/features/uca_minirgb/`, `data/features/uca_mel/`, and `data/features/uca_audio_quality/`; `data/features/uca_feature_manifest.json` records source paths, snippet counts, audio patch counts, and split membership. UCA's train, val, and test videos remain separate. These features were generated for all 48 locally matched clips on 2026-10-08. This prepares features only; interval-supervised training still depends on reviewed labels and a localization loss.

## Fine-tune temporal scores after review

Once you have reviewed both UCA train and val intervals, the optional localization fine-tune is:

```bash
.venv/bin/python scripts/train_uca_localization.py
```

It starts from the current live-compatible binary checkpoint and updates only its per-snippet score head using masked binary cross-entropy. It trains on reviewed UCA train intervals, selects by reviewed UCA val snippet AP, and never loads UCA test. The script requires positive and verified-normal snippets in validation; if the validation table lacks both, it exits rather than selecting a checkpoint from a one-class score. This adapts temporal scores only; it does not retune the clip-level binary classifier or prove better XD-Violence benchmark performance.
